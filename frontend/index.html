Import / Wiederherstellen

Die Wiederherstellung läuft offline auf dem Server. Stoppe die Anwendung vor der Übernahme und erstelle eine neue Datenbank:

python -m wolfs_garage restore-backup BACKUP.sqlite3 NEUE_DATENBANK.sqlite3

Es gibt keinen Upload oder Import im Browser.
